**AI 助手没有 Search Console，所以衡量 GEO 要分两半来做：一半是人工 prompt 审计，直接回答"我们被提到了吗"；另一半是 Google Search Console 的代理指标，用来判断底层信号有没有在移动。** 两件事每月各做一次，用固定的查询词和 prompt 清单，你得到的东西比一个看板更有价值：一份关于工作是否在产生复利的记录。

下面是我们自己在用的流程。每月大约 90 分钟，也是目前唯一经得起实际检验的衡量方式。

## 为什么现在没有可靠的 AI 看板

原因是结构性的，不是某个工具即将补上的空缺：

- **答案是随机生成的。** 同一个 prompt 在不同日期可能给出不同产品，个性化、地区、账号历史都会影响结果。
- **没有曝光数据。** ChatGPT 提到你时，你没有日志、没有点击报告、没有可信的 referrer——大部分 AI 流量在后台里表现为直接访问或暗社交。
- **引用是不透明的。** 助手会引用一部分来源而忽略另一部分；有些答案完全是训练数据拼出来的，根本没发生实时检索。

任何卖给你精确"AI 可见性评分"的人，都是在测一个相邻的东西然后改个名字。你**能**稳定衡量的是输入有没有变好——而这正是 Search Console 能给你的。

## Search Console 能告诉你什么、不能告诉你什么

| 信号             | GSC 里的表现                         | 对 GEO 意味着什么                                                      |
| ---------------- | ------------------------------------ | ---------------------------------------------------------------------- |
| 疑问句查询曝光   | 以 how / what / best / vs 开头的查询 | 模型和搜索者的措辞方式一致——曝光上升说明你的可摘录内容正在匹配真实问题 |
| 品牌词曝光       | 搜索你产品名的次数                   | 被讨论、被推荐的滞后指标                                               |
| 哪些页面拿到曝光 | 页面级效果报告                       | 告诉你哪些资产具备"引用形态"                                           |
| 查询词多样性     | 每个页面对应的去重查询数             | 覆盖广意味着这页在回答一个话题，而不是一个关键词                       |
| 点击与点击率     | 常规效果数据                         | 弱代理——AI 流量往往根本不体现为点击                                    |
| **AI 引用**      | **没有**                             | 需要下面的人工审计                                                     |
| **是否被提到**   | **没有**                             | 同上，需要人工审计                                                     |

这张表的核心纪律是：Search Console 告诉你可引用内容的**供给**是否在生效，人工审计告诉你这些内容是否被**消费**。

## 值得追踪的四个 Search Console 代理指标

打开效果报告，区间选最近 3 个月并对比上一周期，然后取这四个数字：

### 1. 疑问句查询曝光

筛选包含 `how`、`what`、`best`、`vs`、`alternative` 或 `for`（如 "for freelancers"）的查询，逐月记录总量。这是判断你的对比页和 FAQ 内容有没有匹配真实提问方式的最佳单一代理——对搜索引擎和 AI 助手同时成立。

### 2. 品牌词曝光

筛选包含产品名的查询。品牌搜索量是在人们**在别处**遇到你之后才上升的——目录收录、AI 答案、Newsletter。它有数周的滞后，因此是个慢但诚实的确认信号。

### 3. 有曝光、几乎没点击的页面

筛选有曝光但点击接近零的页面。被展示却不被点击的页面，往往是被用来**组织答案**，而不是被访问。这不是失败，这正是"被某个会做总结的系统读取"的特征。

### 4. 每月新增查询数

导出查询词，和上月导出做 diff，数出新增数量。查询词多样性增长，意味着你在一些没有刻意针对的问题上被发现了——这是内容正在被检索系统泛化的迹象。

## 人工 prompt 审计

这一半给你一个直接的答案。每月固定一天，跑同一批 prompt。

**先建立一份 10–15 条的 prompt 清单**，分三组：

- **品类型** —— "最好的[你的品类]工具是什么"、"适合[你的目标人群]的[品类]工具"
- **对比型** —— "[你] vs [竞品]"、"[竞品] 的替代品"
- **问题型** —— 你的产品解决的那件事，用买家会真正问出口的方式表达

**在 ChatGPT、Claude、Perplexity、Gemini 里各跑一遍。** 每次开新会话，并在助手提供联网搜索时打开它——那才是反映"可发现性"的模式。

**每条 prompt 记录四件事，放在一张简单表格里：**

| 字段           | 为什么                                 |
| -------------- | -------------------------------------- |
| 是否被提到     | 核心指标                               |
| 出现位置       | 第一个被提到比第五个值钱得多           |
| 描述是否准确   | 事实说错比不被提到更糟                 |
| 引用了哪些来源 | 你的下一份工作清单——模型信任的那些页面 |

被引用的来源是整套流程里价值最高的产出。如果助手在回答你的品类问题时用了三个目录页和一篇盘点，你现在就明确知道该争取出现在哪四个页面上。

## 固定成每月节奏

90 分钟，每月一次，按这个顺序：

1. **导出 Search Console**（最近 3 个月对比上一周期）→ 记录四个代理指标。
2. **跑 prompt 审计** → 记录是否被提到 / 位置 / 准确性 / 来源。
3. **和上月做 diff** → 记下变化，并给出一个解释。
4. **把引用变成工作** → 被引用最多的页面，就是这个月外链与内容的目标。
5. **刷新一个页面** → 检索偏好近期更新过的页面。挑表现最好的资产，认真改进它。

坚持六个月，你会拥有一件几乎没人有的东西：一份 AI 助手如何描述你产品的纵向记录，以及哪些渠道真正推动了它的证据。

## 复利到底从哪来

衡量只有在指向具体工作时才有用。实践中，推动这些数字的输入相当固定：

- **永久、相关的目录收录。** 结构化的目录页面极易被检索，也高频被引用（详见 [dofollow 目录外链](/blog/dofollow-directory-backlinks-saas)）。
- **品类相关的权威度。** 提及出现在哪里，比提及出现多少次更重要（详见[域名评级与 AI 可见性](/blog/domain-rating-dr-ai-visibility)）。
- **你自己那些可摘录的页面。** 顶部一句话答案、一张对比表、一个真实 FAQ（详见 [GEO/AIEO 指南](/blog/geo-aieo-get-recommended-by-ai)）。
- **所有地方事实一致。** 同样的名称、同样的一句话简介、同样的分类、同样的 URL。

衡量告诉你这些有没有落地，但它替代不了这些工作。

## 常见问题

**有没有工具能自动追踪 AI 引用？**
有几款工具在尝试，用来初步生成 prompt 清单是有用的——但没有任何一款能产出稳定可比的数字，因为助手答案是随机的。把任何单一的"AI 可见性评分"当方向性参考，并以你自己的审计为唯一事实来源。

**AI 可见性审计应该多久做一次？**
每月一次。每周噪音太大无法解读，每季度又太慢，问题会先累积起来。固定每月同一天、同一份 prompt 清单。

**能只用 Search Console 衡量 GEO 吗？**
不能。GSC 显示你的可引用内容有没有匹配到真实问题，这是很强的领先指标，但它无法告诉你助手是否提到了你。那部分必须人工做。

**AI 助手带来的流量会在分析工具里出现吗？**
有时会，表现为来自该助手域名的 referrer，但很多时候不会——用户读完答案后会在新标签页里直接输入你的品牌名。所以要盯品牌词搜索曝光，效果是在那里浮现的。

**最该盯的一个数字是什么？**
Search Console 里的疑问句查询曝光，配合 prompt 审计的"是否被提到"。前者是你这个月就能推动的领先指标，后者是你真正在优化的结果。
