# Blog cover library

Thirty editorial cover images live in `public/images/blog-covers/`. They are
1600 × 900 WebP files, so they fit the blog's 16:9 card and article-header
slots without crop-specific variants. Every image has no text, logo, or
platform-specific mark, making it safe to reuse for translated articles.

## Art direction

The library uses a warm ivory studio background, charcoal objects, aat.ee green,
and a restrained burnt-orange accent. The shared prompt style is a contemporary
editorial paper-cut / soft-sculptural still life with matte material texture,
gentle daylight, and generous negative space. Each cover depicts the article's
idea as a physical system rather than a literal product UI.
